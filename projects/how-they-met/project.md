## Brief

Both parents interviewed about how they met: separately first, then
together, with the versions edited against each other. Their accounts
will differ, and those differences make the episode. You write the
questions, run the recordings, and build the cut; the agent helps
plan the interleave. They hear it before anyone else, and publishing
needs both of their okays.

## Personalize

- **The pair.** Parents, step-parents, or grandparents: any couple
  whose origin story your family retells. If only one will sit for
  it, one deep interview still makes an episode.
- **The questions.** The same list for both separate interviews, so
  the versions line up: first sight, first date, what nearly went
  wrong.
- **The disputed detail.** Every couple has one (whose idea was it?
  who was late?). Ask each of them and keep both answers in the cut.

## Milestones

1. Question list written by you, one version used for both
   interviews.
2. Each parent recorded separately, without the other in the room.
3. The joint session recorded: they tell it together and correct
   each other.
4. The cut built, versions interleaved so agreements and
   contradictions sit next to each other.
5. Both parents hear the episode and approve it, then published at a
   URL or feed (unlisted is fine).

## Done means

- Live at a URL or feed the family can play; unlisted counts
- Both parents consented after hearing the final cut
- Both versions of the story appear; neither is trimmed to make the
  other one win
- Your questions and any narration are your own words
- Voices are clear all the way through; this one gets kept for
  decades
