Worked case: contain a compromised browser script

Trigger: A hosted analytics script begins serving obfuscated code after its vendor account is compromised, and the script ran on login and billing pages while build credentials, cached assets, user sessions, form data, downstream calls, and affected browser versions remain uncertain.

Can we replace the script and purge the CDN?
Contain execution, but preserve served variants, manifests, caches, logs, and credentials first so exposure can still be reconstructed.
The vendor says only analytics was affected.
Browser code had page-origin access. Scope routes, data, sessions, network actions, versions, and time from independent evidence.
Can we rebuild on the usual CI runner?
Not until its source, credentials, dependencies, and integrity are trusted. Use a clean controlled build path.
When can the site return?
After a verified minimal path or clean canary proves asset hashes, headers, critical journeys, and monitoring.

Preserve evidence before trusted recovery.

Failure rehearsal

Disabling the tag breaks authentication because an unrelated loader depends on it. Responders serve a minimal verified login path, preserve cached malicious variants, and block the vendor origin through CSP. A clean build separates the dependency before controlled traffic returns.

Questions people actually ask

Should caches be purged immediately?

Contain delivery while preserving representative malicious assets and metadata under controlled evidence custody.

Must every session be revoked?

Scope the script's access and actions, then apply proportionate session and token containment.

Is a vendor statement enough?

No. Use independent asset, browser, network, build, and deployment evidence.

What makes a rebuild trusted?

Verified source, clean runners, pinned reviewed inputs, new credentials, and reproducible artifacts.

When is the incident complete?

After recovery, exposure decisions, affected-party follow-through, recurrence monitoring, and control verification.

Where to go from here

Inventory browser code with Audit third-party scripts, contain execution with Configure a content security policy, and rotate access with Rotate a compromised secret.
