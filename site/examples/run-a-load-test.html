Failure rehearsal

The generator continues after the controller exits. The operator uses the separate kill switch, confirms request rate returns to baseline, and checks shared dependencies. Results from the affected stage are discarded because the workload no longer matches the recorded plan.

Questions people actually ask

Can we load test production?

Only with explicit owner approval, a bounded plan, dependency coordination, safe test data, and immediate abort control. A production-shaped isolated environment is usually safer.

What is the difference between load and stress testing?

Load testing checks an expected workload. Stress testing deliberately explores behavior beyond the expected range and needs stricter containment.

How long should a test run?

Long enough for the question. A baseline may take minutes; queues, caches, leaks, and autoscaling may require longer held stages or a soak.

Is requests per second enough?

No. Record journey mix, payloads, arrivals, concurrency, think time, data, and cache state because they change system cost.

When should the test stop?

At the first approved abort threshold, unexpected external impact, invalid measurement, or loss of control over the generator.
