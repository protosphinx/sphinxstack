Worked case: move global edge delivery without private cache leakage

Trigger: A global commerce platform must move web pages, APIs, images, downloads, signed links, checkout, login, redirects, WAF, bot controls, rate limits, certificates, DNS, cache invalidation, logs, and origin shielding from one CDN to another while both edges overlap across regions and no private response may leak through a bad cache key.

Can we point all DNS at the new CDN after the homepage works?
No. Compare route, region, identity, cache, security, mutation, and origin behavior before bounded traffic changes.
May both providers use one origin credential?
Use separate revocable provider identities so a failed edge can be fenced without taking down the safe path.
What blocks expansion?
Private cache leakage, security-policy drift, unexplained content differences, unsafe origin load, or loss of traffic authority.
What makes rollback real?
Propagation-aware routing, warm capacity, valid certificates, known cache state, origin protection, monitoring, and tested stop authority.

A successful status code does not prove edge parity.

Failure rehearsal

An authenticated account page is cached without the session variation in one region. The team stops that route, purges both edges, fences the unsafe configuration, traces affected requests, protects users, repairs the cache key and private-response rule, and reruns regional identity tests before resuming.

Questions people actually ask

Can a hosts-file test prove readiness?

No. It misses global DNS, resolver, routing, certificate, and connection behavior.

Should cache rules be copied literally?

Preserve behavior and invariants; provider configuration models may differ.

When can DNS TTLs rise?

After stable delivery and rollback confidence through the intended observation period.

Can the old CDN be disabled after traffic reaches zero?

Not until logs, credentials, certificates, purges, objects, billing, and incident duties close.

How should signed URLs be tested?

Verify scope, expiry, clock skew, region, method, cache, replay, and origin enforcement.
