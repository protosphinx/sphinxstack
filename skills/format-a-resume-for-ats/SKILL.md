# format-a-resume-for-ats

Optimize for clear structure and truthful content, not myths about secret scoring systems.

## When to use

- Use for DOCX, PDF, or portal-text resume submission.
- Do not add hidden text, white keywords, fabricated phrases, or inaccessible visual tricks.

## Procedure

1. Check the employer's current official file, size, naming, and content requirements.
2. Use one logical reading order with standard headings and text-based dates, employers, titles, and locations.
3. Keep contact details and essential content out of headers, footers, images, charts, icons, and text boxes.
4. Use consistent typography, spacing, bullets, and date formats with sufficient contrast.
5. Incorporate role terminology naturally only where the candidate's evidence supports it.
6. Create the requested file type from a clean source and embed or substitute fonts safely.
7. Extract all text and compare its reading order with the visual file.
8. Open the file in multiple viewers, test links, and inspect at typical zoom.
9. Keep a plain-text version for portals that strip formatting.

## Done

- A resume file opens with clear visual hierarchy, selectable text, logical reading order, and working links
- Extracted text and portal preview are checked against the source with no missing, reordered, hidden, or invented content
