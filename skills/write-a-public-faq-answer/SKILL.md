# write-a-public-faq-answer

Answer the question in the first sentence.

## When to use

- Use for product, service, policy, event, public-information, or support content.
- Do not expose private operations, security details, personal data, or promises beyond current authority.

## Procedure

1. Record the exact reader question, audience, context, source of truth, owner, and update trigger.
2. Write a direct one-sentence answer before explanation.
3. Add scope, conditions, steps, examples, deadlines, fees, or evidence only as needed.
4. State exceptions, limitations, and what the answer does not cover.
5. Provide accessible next steps, contacts, escalation, or authoritative links.
6. Test for plain language, translation ambiguity, accessibility, search phrasing, and mobile readability.
7. Verify current facts, links, dates, and owner approval before publication.

## Done

- A FAQ answer draft records question, direct answer, scope, conditions, limitations, next steps, sources, owner, and review date
- Fact, link, date, plain-language, accessibility, search, limitation, and approval checks verify publication
