# consolidate-multiple-resume-versions
## When to use
- Use when several historical and tailored resumes conflict.
- Do not select the most impressive variant without source evidence.
## Procedure
1. Preserve every file, version, date, source, and intended role.
2. Extract claims into one inventory by employer, role, period, achievement, metric, and credential.
3. Group variants and classify supported, stale, conflicting, private, or unresolved.
4. Verify against candidate records and obtain corrections.
5. Create one master chronology and approved claim wording.
6. Generate tailored versions from the master while retaining traceability.
## Failure plan
- Quarantine unresolved claims from new resumes.
## Worked example
Three versions disagree on team size; the master uses the verified direct-report count and preserves broader collaboration separately.
## Done
- A resume master report records source files, claim variants, evidence, dispositions, chronology, approved wording, and outputs
- Date, title, metric, role, credential, privacy, link, source, and tailored-output checks verify consistency
