# create-a-study-timetable

Plan for the hours and attention that really exist.

## When to use

- Use for courses, exams, applications, certification, or independent learning.
- Do not schedule through sleep, care, work, health needs, or immovable commitments.

## Preconditions

- List deadlines, topics, current confidence, fixed commitments, and usable study periods.

## Procedure

1. Break each obligation into learn, practice, retrieve, produce, review, and submit tasks.
2. Estimate effort as a range and identify prerequisites.
3. Reserve fixed commitments, sleep, meals, travel, recovery, and buffer first.
4. Place difficult work in suitable energy periods and use shorter blocks for review.
5. Schedule spaced retrieval and mixed practice rather than rereading alone.
6. Add weekly catch-up capacity and a clear rule for rescheduling missed work.
7. Review actual completion and effort each week, then revise the next week.

## Failure plan

- If the plan exceeds available capacity, reduce scope or seek deadline support.
- If a block is missed, move the task through the catch-up rule instead of stacking it invisibly.

## Worked example

A learner with two exams and a project assigns four retrieval blocks, two problem sets, one project milestone, and a protected catch-up block around work shifts.

## Done

- A study timetable lists dated tasks, effort ranges, prerequisites, recovery, buffers, and rescheduling rules
- Calendar fit, workload, retrieval spacing, deadline, and weekly-completion checks verify that the plan remains realistic
