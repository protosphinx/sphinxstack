# return-to-work-job-search

Translate the present capability without apologizing for the break.

## When to use

- Use for returnships, conventional roles, flexible work, contract work, or a staged return.
- Medical, family, and protected personal details belong to the candidate, not the application.

## Procedure

1. Define target work, hours, location, schedule, travel, physical or access needs, pay floor, support, and transition pace.
2. Inventory current skills and evidence from prior roles, caregiving, study, community work, projects, and recent practice without relabeling unpaid work deceptively.
3. Compare target requirements and choose a small number of current gaps to refresh through real work samples, training, or practice.
4. Build a concise truthful gap explanation focused on present readiness and relevant continuity.
5. Prepare a resume, profile, references, and portfolio that use accurate dates and preserve private information.
6. Identify returnships, alumni, professional communities, recruiters, employers, and arrangements aligned with the constraints.
7. Rehearse inappropriate questions, accommodation timing, salary history boundaries, and confident redirection to job evidence.
8. Run a sustainable application and networking cadence with interview and recovery capacity.
9. Review response patterns and adjust targeting or evidence without treating silence as proof of personal deficiency.

## Failure plan

- If a role's stated schedule conflicts with a nonnegotiable need, clarify early enough to avoid a harmful process.
- If skills evidence is stale, build a bounded current sample instead of inflating recency.

## Done

- A return plan records target roles, constraints, current evidence, refresh work, support, privacy boundaries, and search channels
- Application materials and interview practice communicate the break truthfully while centering current capability and readiness
