# organize-a-media-project

Keep originals immutable and make every derivative traceable to its source and version.

## Procedure

1. Inventory media, project files, applications, owners, storage, backups, and deadlines.
2. Define folders for originals, audio, graphics, proxies, projects, renders, exports, documents, and archive.
3. Use stable identifiers and version names without relying on “final.”
4. Preserve camera originals and checksums before renaming working copies.
5. Link proxies and optimized media to source files and record frame-rate changes.
6. Consolidate fonts, plugins, licenses, color data, captions, rights, and delivery notes.
7. Test backup restore and open the project on a clean authorized workstation.
8. Publish a project map and handoff report with known dependencies.

## Guardrails

- Never move the only copy while restructuring.
- Do not collect licensed assets or private media beyond authorized access.
- Avoid application-specific links that cannot survive a handoff.

## Done

- A project map and file inventory document every production area
- Originals, proxies, versions, and dependencies are verified
- A clean-workstation open and backup restore are tested
