# prepare-for-a-remote-interview

Make technology a tested path, not an unspoken risk.

## When to use

- Use for video, browser-based assessment, remote presentation, or online panel.
- Verify unfamiliar software before installing it and never grant remote-control access to an unverified recruiter.

## Procedure

1. Verify sender, platform, URL, time zone, duration, interviewers, recording terms, assessment rules, and accommodation route.
2. Use a supported, updated device and a separate browser profile or local account when practical.
3. Test camera, microphone, speakers, captions, display name, connection, power, permissions, notifications, and screen sharing.
4. Choose a readable, quiet, stable setup that does not expose private household, employer, client, or screen information.
5. Keep the role brief, examples, questions, water, interviewer contact, and dial-in or alternate link accessible.
6. Rehearse opening, eye-line, concise answers, document sharing, whiteboarding, and stopping screen share.
7. Agree on what happens if audio, video, captions, power, or connection fails.
8. Join at the locally appropriate lead time and close unrelated applications and sensitive tabs.
9. Afterward, revoke unnecessary platform permissions, remove shared files if appropriate, and record commitments.

## Failure plan

- If the platform fails, notify through the verified backup channel and use the agreed fallback.
- If recording or invasive software terms differ from the invitation, pause and request clarification.

## Done

- A remote interview checklist verifies identity, logistics, technology, privacy, accessibility, materials, and fallback
- A rehearsal and post-call record prove critical functions worked and unnecessary access or shared material was cleaned up
