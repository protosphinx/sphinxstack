# evaluate-a-job-posting
## When to use
- Use for a specific current posting and verified employer.
- Do not infer culture, demand, legality, or fit from marketing language alone.
## Procedure
1. Preserve posting, URL, date, location, employer, and application route.
2. Separate responsibilities, must-haves, preferences, logistics, and unknowns.
3. Flag contradictions, vague scope, unpaid work, sensitive requests, and scam signals.
4. Map verified evidence to consequential requirements.
5. Identify compensation, location, schedule, travel, authorization, access, and deadline gaps.
6. Decide apply, clarify, defer, or skip with bounded reasons.
## Failure plan
- Stop if identity, payment request, data collection, or application route is suspicious.
## Worked example
A candidate applies despite two preferred gaps but first clarifies an unexplained on-call requirement.
## Done
- A job-posting evaluation report records source, scope, requirements, evidence fit, unknowns, risks, and decision
- Employer, URL, date, scam, privacy, compensation, access, deadline, and evidence checks verify evaluation
