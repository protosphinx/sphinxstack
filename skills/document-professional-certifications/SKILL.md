# document-professional-certifications

State the current credential status exactly.

## When to use

- Use for licenses, certifications, registrations, clearances, and completed accredited training.
- Do not claim an expired, pending, revoked, provisional, or course-completion credential as active.

## Procedure

1. Verify the credential against the issuer's current official record.
2. Record exact name, issuing body, issue date, expiry or renewal date, jurisdiction, level, and current status.
3. Distinguish license, certification, registration, certificate of completion, membership, and eligibility.
4. Include an identifier only when safe, useful, and permitted; prefer a controlled verification link.
5. Note “in progress” only with an honest expected completion and no implication of current qualification.
6. Select credentials relevant to the target role and place mandatory ones prominently.
7. Check spelling and dates across resume, applications, profiles, and supporting files.
8. Set a review reminder for credentials that can expire or change.

## Done

- A credential list records exact names, issuers, dates, jurisdiction, status, and safe verification route
- Every active, expired, pending, and in-progress label is checked against current official evidence
