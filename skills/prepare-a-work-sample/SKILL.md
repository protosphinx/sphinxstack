# prepare-a-work-sample

Show the work without exposing someone else's information.

## When to use

- Use for writing, design, analysis, code, operations, research, strategy, or presentation samples.
- Create a new bounded sample when existing work is confidential or cannot be explained honestly.

## Procedure

1. Identify the capability the sample must demonstrate and the time or format limit.
2. Confirm ownership, employer or client permission, confidentiality, license, participant consent, and security constraints.
3. Select one artifact with enough context to understand the problem and outcome.
4. Remove or replace personal, customer, credential, financial, proprietary, and security-sensitive content.
5. Add a short note covering situation, constraints, personal role, collaborators, decisions, result, and what changed after feedback.
6. Preserve limitations and do not imply sole authorship of team work.
7. Export in an accessible, stable format with readable text, captions or alternatives, working links, and a neutral filename.
8. Open the final file in a clean account and verify every page, link, permission, and redaction.

## Done

- A verified shareable file demonstrates the target capability and identifies context, personal contribution, collaborators, result, and limitations
- Permission, redaction, accessibility, link, and clean-account checks pass on the exact delivered file
