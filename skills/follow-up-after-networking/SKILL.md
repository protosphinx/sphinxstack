# follow-up-after-networking

## Procedure

1. Review notes, commitments, names, details, and any permission to contact.
2. Send promptly enough that the conversation is still recognizable.
3. Thank the person and reference one specific useful point accurately.
4. Complete any promised resource, introduction, question, or action before asking for more.
5. Offer a bounded next step only when it follows naturally from the conversation.
6. Add the relationship, context, permission, and reminder to a private tracker.
7. Share relevant progress later only when it gives value or closes the loop.
8. Stop repeated follow-up when there is no response or no agreed reason.

## Guardrails

- Do not fabricate familiarity, agreement, urgency, or mutual benefit.
- Never add someone to marketing, a newsletter, or a public contact list without permission.
- Protect private conversation details and contact information.

## Done

- A follow-up message is written, references the real conversation, and completes promised actions
- Any request is specific, proportional, and easy to decline
- The contact record preserves permission, next step, and stop condition
