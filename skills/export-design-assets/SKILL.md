# export-design-assets

Export from an approved source and verify the delivered files.

## When to use

- Use for handoff to web, native, print, social, presentation, or production systems.
- Confirm license and permission before exporting third-party or client material.

## Procedure

1. Inventory each asset, approved source version, use, platform, dimensions, density, format, color space, transparency, and owner.
2. Remove hidden content, private notes, unused layers, embedded credentials, and unnecessary metadata.
3. Choose vector for scalable shapes and appropriate raster or motion formats for visual content and platform support.
4. Export required sizes and densities from one controlled source with deterministic names.
5. Preserve safe zones, crop, transparency, animation timing, compression, and brand constraints.
6. Provide alt-text intent or decorative status separately; do not bake essential text into an image unnecessarily.
7. Open every exported file, compare dimensions and appearance, inspect metadata, and test in the target context.
8. Package a manifest with file, source, version, rights, use, and checksum where useful.

## Done

- An asset package and manifest list verified files, formats, sizes, sources, versions, rights, and intended uses
- Target-context checks prove each export opens, renders correctly, contains safe metadata, and has accessibility guidance
