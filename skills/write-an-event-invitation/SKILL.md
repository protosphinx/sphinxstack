# write-an-event-invitation

## Procedure

1. Confirm audience, event purpose, approved name, date, time zone, location, format, and sender.
2. Lead with the participant value and state who the event is for.
3. Include agenda shape, speakers only if confirmed, cost, capacity, and registration deadline.
4. Explain accessibility arrangements, accommodation requests, language, transport, and remote access.
5. State recording, photography, data, cancellation, and contact information where relevant.
6. Write a direct registration or response action with a working link and deadline.
7. Check plain language, mobile scanning, date clarity, names, and approved claims.
8. Test links and have an event owner approve the final message.

## Guardrails

- Do not imply confirmed speakers, access, approval, scarcity, or benefits that are not secured.
- Never hide material cost, recording, eligibility, or participation conditions.
- Do not expose recipient lists or unnecessary personal information.

## Done

- An invitation draft contains verified logistics, participant value, access details, and action
- Names, claims, dates, time zone, contact, and links are checked
- Approval and final distribution version are recorded
