# prepare-for-a-case-interview

## Procedure

1. Confirm format, timing, role, evaluation criteria, allowed tools, and accessibility arrangements.
2. Build a practice set across issue definition, structure, estimation, data interpretation, tradeoffs, recommendation, and questions.
3. Start every case by restating the objective, decision, constraints, definitions, and missing facts.
4. Create a tailored structure rather than forcing every prompt into one memorized framework.
5. Show calculations with units, assumptions, checks, and sensitivity.
6. Prioritize analysis by likely decision value and update the plan when evidence changes.
7. Synthesize periodically and finish with recommendation, rationale, risk, uncertainty, and next evidence.
8. Use timed mock interviews, specific feedback, an error log, and targeted repeat practice.

## Guardrails

- Do not obtain, share, or memorize confidential live interview cases.
- Never present an unsupported assumption or arithmetic result as fact.
- Do not sacrifice clear reasoning and collaboration for performance theatrics.

## Done

- A practice plan covers structure, quantitative work, evidence updates, synthesis, and communication
- Mock-interview records identify errors, feedback, targeted drills, and improvement
- The candidate can state assumptions, uncertainty, recommendation, and next evidence clearly
