# prepare-a-resume-file-package

Send the exact version intended for the specific application.

## When to use

- Use after content review and before submission.
- Do not include revision history, comments, hidden data, unrelated applications, or sensitive source evidence.

## Procedure

1. Confirm recipient, role, submission channel, deadline, required format, size, and naming rules.
2. Freeze the approved source version and record role, organization, date, and owner.
3. Remove comments, tracked changes, hidden layers, test links, placeholder text, and document metadata that should not be shared.
4. Export required DOCX, PDF, print, or plain-text files from the same source.
5. Name files professionally without sensitive identifiers or internal notes.
6. Open every exported file, extract text, test links, inspect page breaks, and verify contact information.
7. Scan the package for wrong employer names, duplicate versions, private attachments, and malware.
8. Save the sent version and submission proof in an access-controlled tracker.

## Done

- A resume package contains only the required, correctly named, clean, readable, and tested files
- A version and submission record verifies recipient, role, file versions, time, and delivery result
