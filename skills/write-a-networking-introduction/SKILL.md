# write-a-networking-introduction
## When to use
- Use for email, message, event, community, or referral introductions.
- Do not invent familiarity, endorsement, urgency, or personal detail.
## Procedure
1. Verify recipient, relationship path, purpose, facts, and privacy.
2. Open with the genuine shared context.
3. State who you are through one relevant verified detail.
4. Make one small specific request with an easy decline.
5. Remove flattery, autobiography, pressure, attachments, and vague asks.
6. Check names, links, tone, accessibility, and consent before sending.
## Failure plan
- If no legitimate relevance exists, do not manufacture one.
## Worked example
A student cites a public talk, names one shared research interest, and asks for a fifteen-minute informational conversation.
## Done
- A networking message records true context, concise relevance, bounded request, and contact details
- Name, source, privacy, tone, link, consent, and easy-decline checks verify readiness
