# write-a-correction-note

Correct the record without repeating avoidable harm.

## When to use

- Use for articles, reports, data, documentation, announcements, transcripts, captions, or public statements.
- Do not quietly overwrite a material error or blame a source without verified evidence.

## Procedure

1. Confirm affected version, exact error, correct information, source evidence, date, and correction authority.
2. Assess harm, identity, privacy, legal, translation, accessibility, and distribution implications.
3. State the original error precisely enough to locate it without unnecessarily amplifying sensitive content.
4. State the correction, changed locations, timestamp, and effect on conclusions.
5. Link revised versions and note unresolved uncertainty honestly.
6. Propagate the note to derivatives, feeds, partners, archives, translations, and recipients as required.
7. Verify public display, links, dates, access versions, and distribution acknowledgments.

## Done

- A correction note records original error, correct fact, affected version, changes, conclusion impact, date, source, and authority
- Source, harm, derivative, translation, accessibility, timestamp, link, and public-display checks verify correction
