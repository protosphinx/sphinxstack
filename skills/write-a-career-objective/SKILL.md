# write-a-career-objective
## When to use
- Use when direction needs context not already obvious from experience.
- Do not use generic aspiration, unsupported seniority, or employer flattery.
## Procedure
1. Extract target role, problem, environment, and priority capabilities.
2. Select one or two verified evidence points.
3. State the contribution sought and relevant current foundation.
4. Keep it one or two sentences and specific enough to differentiate.
5. Remove clichés, personal need, invented passion, and promises.
6. Check fit with the full resume and candidate intent.
## Failure plan
- Omit the objective when it adds no information.
## Worked example
A laboratory technician seeking data operations names validated sample tracking and reproducible reporting as the bridge.
## Done
- A career-objective draft records target contribution, verified foundation, and realistic scope
- Role, evidence, seniority, specificity, resume-consistency, tone, and candidate-approval checks verify wording
