# organize-a-job-search-week

Plan controllable work, not a promised result.

## When to use

- Use for an active search with several concurrent opportunities.
- Reduce volume when health, caregiving, work, or financial constraints require it.

## Procedure

1. List fixed commitments, available energy, deadlines, interviews, accommodations, and recovery time.
2. Choose a small set of target roles or employers and define what qualifies an opportunity.
3. Allocate blocks for discovery, deep research, tailored applications, networking, interviews, follow-ups, and administration.
4. Protect high-focus time for the work with the highest decision value.
5. Set bounded weekly output targets such as qualified leads researched, applications completed, and people contacted.
6. Add a daily update to the application tracker and an explicit stop time.
7. Schedule a midweek review to reallocate effort around real responses.
8. Close the week by recording outcomes, learning, next actions, and one process change.

Do not let an activity target override health, privacy, job quality, or the actual capacity available that week.

## Done

- A dated weekly plan fits actual capacity and assigns focused blocks to the highest-value search work
- A weekly review compares planned and completed actions, responses, learning, wellbeing, and next-week adjustments
