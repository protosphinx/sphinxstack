# build-an-academic-portfolio

Select work that proves relevant capabilities. Explain the student's contribution and learning without presenting team outcomes as solo work.

## Procedure

1. Define the audience, decision, required format, review time, submission rules, and accessibility constraints.
2. Inventory coursework, research, writing, designs, code, performances, presentations, feedback, and revisions.
3. Map candidate artifacts to the capabilities or criteria the audience will assess.
4. Select a small set showing depth, range, progression, and relevance rather than every completed assignment.
5. For each item, record context, goal, constraints, individual contribution, process, evidence, result, feedback, and reflection.
6. Obtain permission for collaborators, participants, confidential data, unpublished research, and institutional material.
7. Redact or replace protected content and clearly label excerpts, simulations, and team work.
8. Build a simple navigation and test links, files, captions, alt text, reading order, and mobile or print behavior.
9. Ask an independent reader what the portfolio proves, then revise gaps and ambiguity.

## Failure plan

- Never claim sole authorship of group work or publish restricted material.
- Do not include a weaker artifact only because it looks polished.
- If evidence is missing, narrow the claim or add a transparent process note.
- Preserve originals and submit copies in the requested format.

## Done

- Every selected artifact maps to an audience criterion with verified authorship and context
- Permissions, redactions, links, and accessibility checks pass
- An independent review confirms the intended capabilities are visible
