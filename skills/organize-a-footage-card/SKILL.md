# organize-a-footage-card

Do not erase source media until two verified copies exist.

## When to use

- Use for camera, recorder, drone, stills, or field-storage cards after a shoot.
- Preserve the complete card structure when camera metadata, spanned clips, or sidecars depend on it.

## Procedure

1. Assign card ID, device, operator, date, location, project, and custody status.
2. Lock or protect the card and inspect its top-level structure without changing files.
3. Copy the full card to the primary ingest location using checksum verification.
4. Create a second verified copy on independent storage.
5. Compare file count, byte count, hashes, folder structure, and representative playback.
6. Record anomalies, missing clips, corrupt files, clock issues, permissions, and sensitive content.
7. Label destinations and update the ingest log with copy and verification evidence.
8. Release the card for formatting only after the authorized owner confirms both copies.

## Done

- An ingest record lists card identity, custody, destinations, counts, hashes, anomalies, and release authority
- Two independent copies verify against the source and representative media opens with required metadata and structure
