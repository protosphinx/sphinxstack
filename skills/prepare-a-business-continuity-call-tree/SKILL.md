# prepare-a-business-continuity-call-tree
## When to use
- Use for continuity, crisis, evacuation, outage, or emergency coordination.
- Protect personal contact data and never use the tree as proof of staff safety.
## Procedure
1. Define activation authority, scenarios, roles, locations, time coverage, and message types.
2. Record role contacts, alternates, safe channels, languages, accessibility, and consent.
3. Minimize distributed personal data and control access, expiry, and updates.
4. Define call order, acknowledgement, retry, unreachable, escalation, and handoff.
5. Prepare verified message templates and out-of-band fallback.
6. Run a privacy-safe drill and correct delays, gaps, and stale contacts.
## Failure plan
- Move to the alternate channel or local authority when primary communications fail.
## Worked example
A regional outage drill reveals one single-language branch and an expired contractor contact.
## Done
- A continuity call-tree document records activation, roles, contacts, alternates, channels, acknowledgement, escalation, privacy, and ownership
- Consent, access, language, accessibility, stale-contact, unreachable, fallback, drill, and update checks verify readiness
