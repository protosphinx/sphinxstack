# create-an-audio-edit-decision-list

Record decisions precisely enough to rebuild the intended sequence without overwriting the source.

## Procedure

1. Confirm source files, sample rates, timecode basis, transcript, project version, and output structure.
2. Assign stable clip and recording identifiers.
3. Record program in, program out, source in, source out, track, channel, and handles.
4. Note speaker, content, transition, crossfade, processing intent, and narrative role.
5. Flag room tone, music, effects, rights, sensitivity, repair, and alternate takes.
6. Separate editorial timing from destructive cleanup instructions.
7. Include inserts, pickups, narration, and synchronization references.
8. Rebuild or conform a sample section from the list.
9. Save machine-readable and human-readable versions with checksums.

## Guardrails

- Never use the list as permission to alter a speaker's meaning.
- Do not overwrite or renumber original source files.
- Keep private content and clearance restrictions visible to authorized editors.

## Done

- An audio edit decision list records all source and program coordinates
- A sampled conform is rebuilt and verified against the reference edit
- Versions, checksums, rights, and unresolved source issues are documented
