# design-a-multicamera-edit

Choose angles for meaning and continuity, not constant motion.

## When to use

- Use for interviews, performances, panels, events, demonstrations, and live-to-tape productions.
- Preserve complete camera and audio sources before grouping or flattening them.

## Procedure

1. Inventory cameras, audio, frame rates, timecode, clip spans, missing intervals, camera IDs, and rights.
2. Sync with common timecode, waveform, slate, or verified events and test drift across long takes.
3. Assign authoritative audio and camera roles such as master, close, detail, reaction, safety, or screen.
4. Create groups without losing source timecode, metadata, or alternate audio.
5. Mark line crossings, eyelines, continuity changes, flashes, focus failures, and restricted frames.
6. Cut first for story, performance, comprehension, and speaker integrity; use reaction shots only from truthful timing.
7. Preserve action continuity, screen direction, and enough duration for captions and accessibility.
8. Review full program for jump cuts, repeated action, audio changes, sync, pacing, color, and missing coverage.
9. Export a reference with source and edit metadata.

## Failure plan

- If sync drifts, fix the source timing model rather than repeatedly nudging individual edits.
- If no angle supports a truthful continuous moment, use a transparent cutaway or hold the master.

## Done

- A multicamera edit plan records sources, sync, roles, authoritative audio, continuity issues, rights, and edit rules
- Full-program review and test export verify sync, narrative clarity, timing integrity, audio continuity, captions, and source traceability
