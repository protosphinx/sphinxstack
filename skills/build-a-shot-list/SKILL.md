# build-a-shot-list

Describe what the audience must see and why. Keep the list usable on set rather than turning it into a second script.

## Procedure

1. Gather the approved brief, script or outline, deliverables, aspect ratios, runtime, location, subjects, and constraints.
2. Break the story into beats, actions, information, transitions, and emotional changes.
3. Assign each shot a stable ID and record subject, action, framing, angle, movement, audio, location, props, and purpose.
4. Mark must-have narrative coverage, inserts, cutaways, establishing shots, clean plates, alternate formats, and safety takes.
5. Check screen direction, eyelines, wardrobe, props, lighting, time, state changes, and other continuity.
6. Group the list into an efficient production order by location, setup, people, light, and dependency while preserving story order in a reference column.
7. Estimate setup and capture time, identify fragile or unrepeatable shots, and add fallback coverage.
8. Review feasibility with the operator and responsible production lead.
9. Track captured, acceptable, alternate, missing, and intentionally dropped shots during production.

## Failure plan

- Do not specify unsafe movement, access, rigging, or interaction without an approved method.
- Never treat consent, permits, or usage rights as implied by appearance on the list.
- If schedule pressure rises, protect must-have coverage and continuity before optional variety.
- Record changes rather than silently renumbering shots after production begins.

## Done

- Every required story beat and delivery format maps to listed coverage
- Continuity, feasibility, rights, safety, time, and fallback checks pass
- Capture status and any missing or changed shots are recorded at wrap
