# prepare-a-thesis-defense

Defend the actual contribution and its limits, not an idealized project.

## When to use

- Use for thesis, dissertation, capstone, viva, proposal defense, or public examination.
- Do not invent analyses, overstate independence, or conceal corrections and limitations.

## Preconditions

- Gather the submitted version, regulations, format, examiner information allowed by policy, data, code, approvals, and accommodations.

## Procedure

1. Create a claim-evidence map for question, contribution, methods, results, limits, and implications.
2. Build a concise narrative explaining the problem, choices, findings, and what remains unknown.
3. Verify every figure, number, quotation, citation, and version against the submitted thesis.
4. Prepare method, alternative explanation, ethics, validity, literature, and contribution questions.
5. Rehearse concise answers that distinguish evidence, interpretation, uncertainty, and future work.
6. Run full and compressed presentations with neutral reviewers.
7. Test room or call, files, fonts, media, backups, timing, accessibility, and recovery.
8. Record issues requiring correction and follow the formal post-defense process.

## Failure plan

- If a material error is found, disclose it through the authorized process before presenting it as reliable.
- If technology fails, use the tested offline or verbal route.

## Worked example

A candidate demonstrates the main result, explains why causal inference is limited, answers an alternative-model question, and records a mislabeled appendix figure for correction.

## Done

- A defense package contains claim-evidence map, verified deck, question bank, rehearsal report, logistics plan, and correction list
- Submitted-version, timing, figure, citation, limitation, accessibility, backup, and mock-question checks verify readiness
