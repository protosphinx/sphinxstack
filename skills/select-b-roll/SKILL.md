# select-b-roll

Choose every shot for a defined narrative function and verify that its context matches the words it covers.

## Procedure

1. Read the current edit, transcript, claims, tone, and missing visual information.
2. List needs for establishing, process, detail, evidence, reaction, transition, and breathing room.
3. Search logged footage by exact source and time range.
4. Check date, place, people, action, sequence, rights, and editorial context.
5. Choose handles, screen direction, continuity, composition, motion, and technical quality.
6. Avoid literal filler when a shot would imply unsupported causality or identity.
7. Place selects in a string-out with source notes and alternates.
8. Review the sequence muted and with narration, then verify every used source.

## Guardrails

- Never use unrelated footage as if it depicts the named event.
- Do not cover an edit that materially changes a speaker's meaning.
- Respect privacy, safety, consent, and clearance restrictions.

## Done

- A B-roll select reel and source list are saved
- Context, rights, continuity, and technical quality are verified
- The final sequence supports rather than contradicts the spoken claims
