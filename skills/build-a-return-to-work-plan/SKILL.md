# build-a-return-to-work-plan
## When to use
- Use after care, health, study, relocation, redundancy, or another break.
- The person controls disclosure and pace.
## Procedure
1. Define goals, constraints, capacity, income needs, access, and privacy.
2. Inventory verified prior and break-period evidence.
3. Select realistic target roles and identify currency gaps.
4. Build small current proof, refresh learning, references, and materials.
5. Schedule bounded networking and applications with recovery time.
6. Review evidence, wellbeing, response, and target fit regularly.
## Failure plan
- Reduce pace or seek qualified support when work search harms health or safety.
## Worked example
A caregiver pilots two weekly applications and a current operations project before increasing pace.
## Done
- A return-to-work plan records targets, evidence, gaps, refresh work, privacy, pace, applications, support, and reviews
- Capacity, income, access, evidence, disclosure, schedule, wellbeing, and review checks verify sustainability
