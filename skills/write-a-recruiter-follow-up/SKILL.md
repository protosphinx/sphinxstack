# write-a-recruiter-follow-up

Make the message easy to answer.

## When to use

- Use after an application, screen, promised update, or reasonable silence.
- Do not send repeated messages inside the recruiter's stated response window.

## Procedure

1. Record the role, contact, last interaction, promised timing, time zone, and the outcome you need.
2. Verify the recruiter and address against the employer's official domain and prior thread.
3. Reply in the existing thread when possible with a specific subject otherwise.
4. Open with the shared context, then state continued interest in one sentence.
5. Add one useful update only if it changes candidacy, such as availability or a relevant completed project.
6. Ask one answerable question about status, next step, or timing.
7. Close politely without inventing urgency, competing offers, or personal familiarity.
8. Proofread names, role, dates, links, attachments, and tone before sending.

## Done

- A verified ready-to-send email identifies the role, shared context, current interest, and one clear question
- The message contains no fabricated leverage, unnecessary personal data, or pressure beyond the actual timeline
