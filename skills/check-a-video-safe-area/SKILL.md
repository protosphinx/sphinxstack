# check-a-video-safe-area
## When to use
- Use for titles, lower thirds, subtitles, logos, calls to action, and key action.
- Do not use one legacy guide as proof for every modern platform.
## Procedure
1. Record master dimensions, aspect, intended variants, devices, players, and overlays.
2. Load current platform guides and player controls.
3. Test title, action, caption, logo, and interactive safe regions.
4. Preview crop, fit, fill, vertical, square, widescreen, television, mobile, and embedded states.
5. Check caption collisions, readable size, contrast, motion, and translation expansion.
6. Export representative frames and record required revisions.
## Failure plan
- Recompose variants when one master cannot preserve meaning safely.
## Worked example
A vertical crop covers a speaker’s name with platform buttons, so the lower third moves and shortens.
## Done
- A video safe-area report records formats, guides, overlays, essential content, captions, crops, and revisions
- Mobile, television, vertical, square, crop, control, caption, translation, contrast, and frame checks verify visibility
