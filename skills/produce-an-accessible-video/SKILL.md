# produce-an-accessible-video

Plan access before picture lock.

## When to use

- Use for public, educational, workplace, product, event, social, or training video.
- Do not treat automatic captions as finished evidence.

## Procedure

1. Define audience, languages, player, delivery contexts, content risks, and accessibility requirements.
2. Write or shoot so important visual information is spoken naturally where possible.
3. Reserve time and space for captions, sign-language interpretation, lower thirds, graphics, and description.
4. Record clear speech, identify speakers, limit competing audio, and explain meaningful sounds.
5. Create a transcript with speakers, speech, meaningful sound, and relevant visual information.
6. Author timed captions with accurate words, speakers, sounds, line breaks, reading speed, position, and no obstruction.
7. Create audio description or a described version when important visuals are not otherwise available.
8. Check contrast, text size, flash, motion, color-only meaning, pronunciation, cognitive load, and pause time.
9. Test the encoded video, caption track, transcript, description, controls, keyboard, screen reader, mobile, and alternate languages.

## Failure plan

- If access content cannot fit the locked edit, reopen the edit or publish a verified equivalent version.
- If a platform strips tracks or controls, provide an accessible alternate player or download.

## Done

- An accessibility package contains verified video, captions, transcript, description decision or track, languages, and known limitations
- Playback tests verify accuracy, timing, readability, audio, visuals, keyboard, screen readers, controls, mobile, and platform delivery
