# conduct-an-archival-research-project

Treat the archive as a constructed record, not a transparent window.

## When to use

- Use for institutional, historical, legal, cultural, biographical, or community research.
- Respect repository rules, cultural authority, privacy, copyright, embargoes, and vulnerable people.

## Preconditions

- Define questions, periods, places, actors, concepts, budget, travel, language, access, and handling obligations.

## Procedure

1. Build a repository and collection map from finding aids, catalogs, citations, experts, and community knowledge.
2. Request access, permissions, equipment, accommodations, and restricted-material guidance early.
3. Record collection, series, box, folder, item, version, provenance, custody, restriction, and citation rules.
4. Use a capture log linking each note or image to its exact locator and filename.
5. Search systematically while logging terms, date ranges, exclusions, gaps, and inaccessible material.
6. Critique creation, survival, arrangement, description, silence, power, authenticity, and representativeness.
7. Corroborate consequential claims across independent records and explain contradictions.
8. Preserve secure notes, citations, permitted copies, redactions, and an audit trail.

## Failure plan

- If access is refused, document the boundary and use lawful alternatives without implying completeness.
- If sensitive records could harm living people, pause disclosure for qualified ethics and legal review.

## Worked example

A labor-history project links photographed memos to box and folder IDs, logs unavailable personnel files, and tests management records against union newsletters and oral histories.

## Done

- An archival research report includes repository map, search log, source register, exact citations, access limits, provenance, and argument evidence
- Permission, filename, locator, custody, corroboration, privacy, completeness, and reproducibility checks verify the record
